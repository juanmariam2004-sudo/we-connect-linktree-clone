# We Connect – Linktree Clone

## About the Project
We Connect is a web-based platform inspired by Linktree that allows users to organize and share multiple links through a single page.

## Technologies Used
- HTML
- CSS
- JavaScript
- MongoDB

## Key Features
- Simple and user-friendly interface.
- Organized display of personal links.
- Responsive web design.
